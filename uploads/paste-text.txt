我需要你帮我构建一个名为“Atoms Studio”的Web应用。这是一个AI驱动的应用生成器，核心设计理念是“对比与选择”——让用户在多个AI方案中比较，选出最适合自己的版本。请帮我开发一个可直接运行的网页，使用React + TypeScript + Vite + Tailwind CSS + shadcn/ui 技术栈。

## 一、核心交互（满足笔试基本要求）

1. 用户可以在文本框中输入自然语言需求（例如：“帮我生成一个待记事项管理应用”）。

2. 【核心差异点1：双列对比预览】点击生成后，系统同时调用同一个AI模型两次（或使用两个不同的Prompt策略），并排生成两个不同风格/架构的HTML应用。左右两列同时展示生成过程和最终结果，用户可以直观对比并选择更满意的版本。

3. 【核心差异点2：Agent思维链可视化】生成过程中，右侧或底部面板实时展示AI的“思考过程”——以折叠面板形式展示“需求理解”、“技术选型”、“组件设计”、“样式方案”四个阶段的推理摘要，让用户看到AI是如何一步步构建应用的。

4. 生成完成后，左右两侧的预览区分别展示两个版本的应用，用户可以通过点击“选择此版本”按钮将心仪的版本保存到“我的应用”中。

5. 数据持久化：每个保存的应用包含：用户需求、选中的代码、另一个版本代码（供后续参考）、选择理由、创建时间。所有数据保存在IndexedDB中。

## 二、差异化功能设计（创新性体现）

1. 【风格偏好学习】在“我的应用”列表中，增加一个“风格统计”小模块，统计用户选择过的所有应用中，更倾向于哪种风格（如：简约风/卡片风/数据看板风），这是一个简单的偏好学习机制。

2. 【方案对比记录】每个已保存的应用都可以展开查看“对比历史”，显示当初两个版本的区别摘要，方便用户复盘为什么选择这个版本。

3. 【一键导出+分享】每个已保存应用提供“导出HTML”按钮，同时生成一个简单的“分享链接”（使用URL编码压缩数据），方便用户分享给他人预览。

## 三、UI/UX要求

1. 整体使用浅色明亮主题+毛玻璃效果（Glassmorphism），营造“创意工坊”的氛围，与Atoms的深色科技感形成视觉差异。

2. 工作区为三栏布局：左侧为对话区（宽25%），中间为预览A（宽37.5%），右侧为预览B（宽37.5%），强调“对比”的核心体验。

3. 思维链面板位于底部，可折叠展开，默认收起，不影响主流程。

4. 生成过程中，预览区显示骨架屏或加载动画，而非空白等待。

5. “我的应用”列表以卡片网格形式展示，每个卡片显示应用名称、创建时间和操作按钮（加载/导出/删除）。

## 四、数据持久化要求

1. 使用IndexedDB（配合Dexie.js）实现数据持久化，确保刷新页面后数据不丢失。
2. 支持按应用名称搜索。
3. 每个应用保存多个历史版本（至少5个），支持查看历史记录。
4. 数据结构设计为可扩展格式，预留userId、tags、isPublic等字段，便于未来接入云端。

## 五、技术要求与实现约束

1. 【LLM适配器模式】代码中必须实现一个LLM适配器，支持三种运行模式：
   - `atoms` 模式：通过后端代理调用模型（默认），确保API Key不暴露在前端
   - `openai` 模式：直接调用OpenAI兼容端点，支持用户在前端配置自定义API Key
   - `mock` 模式：离线降级方案，当LLM调用失败时自动使用预置模板返回结果，确保Demo始终可演示

2. 【代码解析降级策略】AI返回的代码必须经过解析器处理，支持三层降级解析：
   - 优先识别 `--index.html--`、`--style.css--`、`--app.js--` 分隔符标记
   - 降级到从Markdown代码块（```html```、```css```、```javascript```）中提取
   - 最后兜底：将整个AI输出作为完整的HTML文档直接渲染
   - 任意一层解析成功即停止，确保LLM输出格式变化时系统仍可工作

3. 【预置模板库】至少预设3个常用应用模板（如：待办清单、记账本、番茄钟），每个模板包含完整的HTML/CSS/JS代码。当LLM调用失败或用户处于离线状态时，系统自动匹配并返回对应的模板代码。

4. 【UI设置面板】在界面中增加一个设置入口（齿轮图标），允许用户：
   - 切换LLM模式（atoms / openai / mock）
   - 配置API Key（openai模式用）
   - 配置API Base URL（支持切换不同模型提供商）
   - 所有设置保存在localStorage中，刷新后保留

## 六、技术实现说明

1. 使用OpenAI API或兼容接口，每次调用时使用两个不同的System Prompt来产生风格差异：
   - Prompt A：“你是一个极简主义前端工程师，追求代码简洁、视觉干净、功能实用。”
   - Prompt B：“你是一个创意型前端工程师，喜欢丰富的视觉元素、动画效果和交互动体验。”

2. 生成的代码必须是在浏览器中可直接运行的完整HTML文件（内联CSS和JS），确保iframe预览无额外依赖。

3. 整体技术栈：React 18 + TypeScript + Vite + Tailwind CSS + shadcn/ui + Dexie.js + Zustand（状态管理可选）。

## 七、可交付成果

1. 完整的可运行Web应用，所有核心功能可交互。
2. 代码结构清晰，有合理的组件拆分和类型定义。
3. 提供部署到Vercel的配置，确保可一键部署上线。
