# Project Context

## Project Overview
**atomsDemo** —— 智能体驱动的 Web 应用生成平台。用户输入一句自然语言需求，由 4 个内置智能体（团队领导 / 产品经理 / 全栈开发工程师 / 测试工程师）串行流水线协同工作，自动产出可运行的单文件 HTML（内联 CSS + JS）应用，在 iframe 沙箱中可视化预览，并支持代码编辑、对话式迭代修改、运行时错误一键修复、项目与版本持久化管理、单文件 HTML 导出下载。

核心定位：零代码门槛，从「一句话需求」到「可运行应用」全流程智能体驱动。
目标用户：无开发能力但有想法的普通用户、需要快速验证原型的项目经理、想参考完整代码的前端新手。

## Constraints
### 硬性约束（来自需求文档）
1. LLM 输出必须**先收集完整再解析**，禁止流式实时解析代码。
2. 输出格式：先 1~2 句说明 → 分隔符代码块 → 代码后不得有任何内容。
3. iframe sandbox 必须为 `allow-scripts allow-same-origin`，否则 localStorage 不可用。
4. 对话历史保存前必须**剥离代码块**，避免上下文膨胀。
5. 对话改码 prompt 必须强调：保留原有代码 + 最小化修改 + 输出完整文件。
6. 新建/删除项目后必须触发列表刷新（`projectListVersion` 版本号）。
7. `clearChat()` 必须同时重置 `isChatting` 状态。
8. 生成的应用仅限 HTML/CSS/JS 三件套；下载产物不得包含平台自身 UI。
9. 版本最多保留 20 个，版本号递增。
10. 校验重试最多 3 轮；测试缺陷修复最多 2 轮，超限标注「未完全通过测试」。
11. 命令过长时使用临时文件存储后传入。
12. 代码文件数量控制在合理范围，MVP 优先跑通端到端主链路。

### 设计规范
- 风格：现代简约 + shadcn/ui 风格，**暗色主题为主**（背景 `#0f172a` 系列 slate 深色）。
- 主色：slate 深色底 + indigo/violet 强调色；思考过程用紫色主题（violet/purple）。
- 布局：顶栏（logo + 用户信息 + 设置 + 登出）+ 左栏（项目列表，可收起）+ 右栏主工作区。
- 主工作区三态：需求输入页 → 生成中页（4 阶段进度）→ 结果页（预览/代码/分屏三视图 + 底部对话面板）。
- 分屏支持拖拽调宽（20%–80%）；对话面板支持上下拉高并冻结在底部。
- 访客模式显示明显「访客」badge。
- 字体：系统无衬线 + 代码区等宽字体。
